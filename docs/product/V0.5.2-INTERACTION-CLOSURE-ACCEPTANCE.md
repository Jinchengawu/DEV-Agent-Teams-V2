### 2.2 Interpretation

1. 新增能力保持 Project lifecycle、ACWM、Evidence、Release 和 Apply 的既有权威边界，没有建立第二套状态权威。
2. 本地自动化和完整 Deterministic 浏览器证据足以支持 `Local Contract Verified / Deterministic Browser Verified`，不足以支持 `Release Candidate` 或 Live 通过。
3. dirty worktree 的浏览器结果证明当前文件集合的行为，不是可复现的冻结 Git Revision 证据。

### 2.3 Assumption

1. v0.5.2 仍以受控本地 Alpha 为目标，而非公网生产 SaaS。
2. 用户已授权隔离本地评测的 Plan/Design Gate；Candidate/Release Gate、Apply 和远端 Git 写入仍需独立授权。
3. `/private/tmp` 浏览器证据在本机当前会话可读，但不是长期归档位置。

### 2.4 Unknown

1. 冻结 Workcell 在长时运行中的间歇性超时 P95/P99 与连续多轮稳定性；最新单次完整轨道已通过，不代表长期 SLA。
2. 当前实现合并并冻结为唯一 Revision 后，Browser、Deterministic 与 Live Release Gate 是否能同时零容差通过。
3. 正式候选的 P95/P99 时延、恢复稳定性和长期运行表现。
