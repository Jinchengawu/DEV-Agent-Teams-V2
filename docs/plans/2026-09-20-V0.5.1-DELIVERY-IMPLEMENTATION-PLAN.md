## 3. Architecture Review

### Architecture Impact

`Cross-boundary`

原因：本计划不改变业务权威，但改变 Python Runtime 与分发资源之间的定位契约，并将 Console、
Migration、配置和后端制品组合为一个交付边界。这跨越 Runtime、Build、Static UI 与 Operations。

### Findings

1. 现有 `Path(__file__).parents[2]` 把 Preview Runtime 隐式绑定到源码 checkout；安装包没有表达该依赖。
2. Python wheel、Console dist、Migration 与配置各自存在，但没有一个权威 Manifest 将它们绑定到同一 Revision。
3. 已有 Delivery Handoff Evidence 是证据索引权威；新 Bundle 不得复制 Release/Gate 判定。
4. ACWM、Agent-Team-OS、AgentScope、Hermes 与 Codex 的既有权威边界不受本计划改变。
5. Product Root 属于受信任运行配置，必须验证路径和资源完整性，不能接受任意不完整目录静默回退。
6. Bundle 必须排除数据库、日志、缓存、凭据和用户工作区，避免扩大安全边界。

### Required Revisions

1. 将“wheel 自包含”修订为“Delivery Bundle 自包含”；wheel 仍是 Bundle 内的后端安装物。
2. Product Root 必须显式优先、严格校验；仅在未指定时才使用源码 checkout 默认根。
3. clean-room 验证必须证明没有读取原工作区资源。
4. Manifest 只描述制品事实，不包含 Gate 通过或 Apply 成功字段。
5. 实施切片应先建立失败测试，再改 Runtime 和 Builder。
6. 架构文档只能在实现和验证后记为 `Implemented/Verified`。

### ADR Required

`Yes`。

分发根与 Runtime 资源发现策略是新的跨模块集成策略；需要 ADR 记录为何选择 Bundle Product Root、
回退规则、安全约束及被拒绝方案。建议编号由实施 Agent在现有 ADR 序列中确认。

### Architecture Document Delta

实现完成后，更新 `docs/architecture/ARCHITECTURE.md`：

1. 在 Runtime/Adapter 或 Operations 边界加入 Delivery Bundle 与 Product Root；
2. 在安全边界加入 Bundle deny-list 与无凭据要求；
3. 在验证边界明确 Bundle clean-room smoke 仅为 Local evidence；
4. 在状态索引中记录 ADR 和实际验证状态。

### Outcome

`Approved`

该 Outcome 只批准本计划进入实现，不批准任何 Release Gate 或 Apply。

## 4. Revise Plan

依据 Architecture Review，将实现收敛为一个最小纵向切片：

`统一身份 → 构建 Delivery Bundle → 显式 Product Root 启动 → clean-room 验证 → 文档 reconciliation`

不在本轮实现：容器、远程 Registry、制品签名服务、自动升级、正式 Live Provider 修复、四仓资格刷新、
AgentScope Adapter、Release Approval 或 Apply。

### WP-2 Delivery Bundle 与 Manifest（DLV-002、DLV-004）

**Owner**：实施 Agent
**依赖**：WP-1

动作：

1. 新增最小 Bundle builder，输入已构建 Python/Console 制品与仓库资源。
2. 复制后端安装物、`console/dist`、`migrations`、运行所需锁定配置和经追踪确认的 Method Pack 资源。

5. 不在 Bundle 中写入 Gate 结论或外部凭据。

验收：正常输入可生成并校验 Bundle；缺资源、篡改、敏感文件或版本漂移均被测试拒绝。

### WP-3 Product Root 与 Runtime 兼容（DLV-003）

**依赖**：WP-2

## 9. 风险与止损

| 风险 | 保护措施 | 停止/升级条件 |
|---|---|---|
| Bundle 遗漏动态资源 | 代码路径追踪 + 缺失资源测试 | 必须复制未知用户目录或大范围仓库时停止 |
| Product Root 可被用于路径越界 | 绝对化、存在性/结构校验、无静默回退 | 需要扩大 Workspace 权限时停止 |
| 构建包含秘密或运行数据 | allow-list 优先 + deny-list 测试 | 发现凭据立即停止并只报告位置类别 |
| 版本对齐破坏兼容 | focused regression + canonical version | 需要改变公共 API schema 时重新架构审查 |
| Local 证据被误认成 Live | 报告状态分栏 + 文档约束 | 无同 Revision Live 报告时保持 blocked |
